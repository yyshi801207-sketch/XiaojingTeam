# 持久群任务

[English](guide.md) | 中文

## 变更

群目录现在写入 `katcats_chats_v3`。首次打开导入已提交的 v2，否则导入 v1，不改变前代。v3 提交后即为权威数据，数据损坏不会触发前代回退。旧可执行程序不能读取当前任务状态，不支持降级。

新准入输入携带 `coordinationVersion: 1`。业务任务跨轮次保留，明确归类缩小自动追加的历史范围，已确认阻塞保留有次数限制的负责人解释义务。已有已准入输入保留原行为。停止和未知结果保护继续有效。工具、共享上下文行为及限制见[群聊参考](../../../../packages/api/katcats-team/README.zh.md)。

## 迁移

1. 保留全部群存储和 Session 日志。使用相同配置目录启动更新后的程序，不要删除 v3 强制重新导入。
2. 更新自定义指令，使用 `record_group_task` 记录任务延续与验收条件，使用 `find_group_tasks` 定位旧任务。轮次结束不代表用户验收通过。
3. 重启后先核验已保存结果，再继续暂停的工作。已确认阻塞可以触发解释，不能授权重做操作。确认停止后不会自动恢复解释任务。
4. 继续前核验已有群组、待办、文件和消息身份。宣称 token 节省或质量不变前，应使用相同模型对照真实任务。
