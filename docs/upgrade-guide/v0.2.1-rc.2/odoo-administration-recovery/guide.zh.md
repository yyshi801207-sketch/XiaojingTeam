# Odoo 管理操作恢复

[English](guide.md) | 中文

## 变更

两位固定 Odoo 助手不再跨管理数据库沿用聊天摘要和已保存的 Bot 或团队记忆。新连接上下文会替换模型可见的旧历史，原始 Session 日志保留。旧版助手 Session 的首次请求也会建立新上下文。同一已验证账号和数据库更换密钥时保留上下文。助手执行期间，不允许更换会导致上下文变化的连接。

管理写入会先持久化操作，再发送请求并回读受影响记录。未确认的写入会阻止同一助手在该数据库继续写入，重启后仍然有效，但可以继续只读查询。账套初始化可使用明确选择的空公司；公司创建结果不明时，可从已保存的建账任务核对恢复。

## 迁移

1. 更换管理数据库或账号前，先停止正在执行的助手任务。在任一助手的 **Bot 设置 → 财务系统连接** 中保存并验证连接。
2. 升级或切换上下文后，重新说明当前任务，并在当前数据库查询目标公司和记录。旧聊天和保存的记忆仍然留存，固定助手不会自动使用它们。
3. 管理写入结果未确认时，让对应助手查看已保存的操作并核对受影响记录。创建回执丢失时，先检查候选记录，再明确认领；结果未知期间不要重复创建。
4. 引导建账中的公司创建结果未确认时，打开 **连接器 → 建账任务**，检查候选并确认对应公司，然后单独确认继续建账。核对任务达到 **账套已就绪**，且回读结果包含初始化后的公司、科目和日记账。
