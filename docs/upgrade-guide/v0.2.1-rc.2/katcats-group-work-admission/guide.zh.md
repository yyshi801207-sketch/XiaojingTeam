# Katcats.AI 群体工作需要真实成员贡献

[English](guide.md) | 中文

## 变更

用户交给多成员群体的任务，在其他成员实际贡献前不能使用业务工具。接话成员会收到完整的当前名录和生效群内职责，可通过 `plan_group_work` 记录分工，再分别调用 `request_group_member`。计划中每名成员都必须实际完成回复，之后才在新模型步骤进行整合。记录计划、任务排队或确认跳过均不满足这个要求。

明确单独点名、一名成员的群，以及其他成员已经派来的工作，仍可独立执行；问候、群设置及作用域记忆无须多余派活。`present` 可直接登记已有最终文件，不必重新发起工作；未完成的已声明计划、同一步派活及原有权限和文件校验仍然有效。真实交接正文完整显示在群内，也可进入后续成员上下文，保留工具交接来源，不伪装成 assistant 发言。存储字段和 Session 事件类型不变；重启后仍暂停未完成工作。

## 迁移

1. 运行更新后的独立 Katcats.AI 构建，无须手动迁移数据。
2. 对面向群体的任务，由接话成员选择相关同事并等待真实结果；明确只交给一名成员的任务仍可独立执行。
3. 核对分工记录、真实成员回复和最终文件的顺序；审核草稿时可阅读完整交接正文并打开文件链接。
