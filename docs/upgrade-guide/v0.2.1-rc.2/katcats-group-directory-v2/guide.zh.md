# Katcats.AI 群聊目录使用独立 v2 数据域

[English](guide.md) | 中文

## 变更

本次变更仅影响独立的 Katcats.AI 产品。群聊可以和 Bot 共用自定义侧栏分组。原来的 `katcats_chats` 数据域只允许默认群聊分组；新写入使用版本为 2 的 `katcats_chats_v2` 数据域。

首次启动且尚未提交 v2 记录时，Katcats.AI 读取并校验 v1，将完整群聊目录和待完成操作导入 v2。原 v1 代际的字节保持不变。会话身份、历史和工作目录中的文件均予以保留。v2 一旦提交即成为权威记录，校验或读取失败时不会回退到 v1。不支持对迁移后的产品数据降级，因为保留的 v1 记录不包含后续 v2 变更。

## 迁移

1. 使用原有的独立产品数据位置启动更新后的 Katcats.AI。无需手动移动文件、编辑数据或修改配置；现有 Katcats.AI 启动流程会完成导入。
2. 确认已有 Bot 和群聊仍在列表中，对话可以打开，且群聊可以移入自定义侧栏分组。使用 JSON 后端时，新记录为 `katcats_chats_v2.json`，原 `katcats_chats.json` 保持不变。
3. 如果启动报告校验或迁移错误，先停止，解决报告的问题后再重试更新后的版本。迁移失败不会重置记录。不要通过删除或编辑任一代际绕过错误，也不要用旧产品版本打开迁移后的数据。

当前产品行为见 [Katcats 团队存储文档](../../../../packages/api/katcats-team/README.zh.md)。
