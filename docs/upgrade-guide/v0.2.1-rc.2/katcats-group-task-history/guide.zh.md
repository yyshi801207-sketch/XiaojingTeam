# Katcats.AI 在群历史中记录任务协作

[English](guide.md) | 中文

## 变更

这项变更仅影响独立 Katcats.AI 产品。群历史包含仅用于日志的 `katcats/group-task-lifecycle` 事件，记录已接收任务、实际执行状态与失败。这些记录保存真实发起者、接收者和指令，不冒充成员回复，也不授予权限。不识别该必读事件的旧版本会拒绝读取更新后的 Session 日志。现有事件类型标识可以防止不安全解释，因此 Session 格式版本保持不变。

更新后的版本可读取旧群历史，并从现有持久任务记录补齐缺失记录，不重复执行模型任务。恢复的记录有明确标识，其记录时间不作为原始执行时间。既有 Session 代、消息和文件均保留。

## 迁移

1. 使用更新后的独立 Katcats.AI 版本，沿用原产品数据位置。无需编辑配置、移动文件或手动修改数据。
2. 打开群，通过真实成员提交任务，确认任务记录显示实际接收者和排队或开始状态，随后显示真实结果。成员仅口头声称已分派，不会生成分派记录。
3. 重新打开更新后的版本，确认同一任务记录和成员回复仍在，并未重复派发。这些 Session 应继续使用更新后的版本；不要通过删除日志事件或重置数据绕过旧版本的拒绝读取。如果保存或恢复未能确认，应先解决报告的错误，再继续受影响群的任务。

独立目录与群行为见[产品存储说明](../../../../packages/api/katcats-team/README.zh.md)。
