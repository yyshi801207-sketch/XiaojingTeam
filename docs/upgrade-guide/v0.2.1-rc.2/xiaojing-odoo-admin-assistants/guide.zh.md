# 从主 Bot 卡片打开 Odoo 管理助手

[English](guide.md) | 中文

## 变更

原独立建账助手移入主 Bot 视图，负责公司与组织、建账与账套维护。系统助手负责用户与权限。两位助手使用同一已验证的 Odoo 管理连接，各自保留独立私聊。建账助手沿用原建账会话和任务记录。

## 迁移

1. 点击主 Bot 卡片左上角的助手缩略图，切换到并排显示的两位助手，每位显示 64 像素头像和名称。点击建账助手打开既有建账会话，点击系统助手管理用户与权限。点击主 Bot 缩略图可恢复主 Bot 卡片。
2. 在任一助手的 **Bot 设置 → Odoo 数据库连接** 中核对已保存的地址和数据库。打开 **连接器 → 建账任务**，确认既有方案可用。批准管理写入前，先在确认面板核对具体的 Odoo 操作。

有关操作范围和共用连接，见 [Odoo 管理与账套初始化](../../../../packages/api/katcats-team/README.zh.md#odoo-administration-and-ledger-setup)。
