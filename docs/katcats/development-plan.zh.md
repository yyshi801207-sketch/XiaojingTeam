# Katcats.AI 开发与验收计划

[English](development-plan.md) | 中文

本参考文档定义独立 Katcats.AI 工程的开发阶段与验收条件。计划中的目标不代表功能已经可用。开发按阶段顺序推进，上一阶段验收通过后自主继续下一阶段。

## 产品范围

- 在 `E:\Projects\Katcats.AI` 的 Katcat.AI 独立源码副本上开发，保留 DSH 和现有产品界面。以 Grok Bot 为产品参照、DeepSeek Bot 为实现参考，不预设整套安装 ds-bot 插件。
- 左侧上方固定主 Bot，负责成员创建和配置，通过自然语言需求实际创建成员，只有保存成功后才报告成功；不默认加入或管理群聊。
- 提供只需名称和头像的快速创建入口。手动创建的 Bot 初始为通用助手，用户可以直接与它聊天安排长期身份。
- 复用工作区列表交互来管理逻辑 Bot 分组。首次显示普通 Bot 和群聊分组，空组也保留；每个分组都有对应的新建按钮。
- 选择 Bot 后打开其对话，并在右侧设置名称、职责、头像、颜色和模型。新 Bot 默认使用本产品单独配置的 DSH 基础模型，初始以 DeepSeek 为基础。
- 支持创建群聊、成员身份、真实模型接话、派活、记忆、权限、审批和用量统计，依据下方能力对标表检查交付范围。
- 使用 Katcats.AI 名称和已批准猫咪素材，包括用户提供的橙色 S 字标。保留许可，默认浅色，尊重已保存主题，完整支持深色和减少动态效果。

## 初版实现决策

以下默认值用于明确用户尚未逐项指定的细节，属于实现选择，不是对 Grok Bot 或 DeepSeek Bot 现状的声明；后续可在保留已确认产品范围的前提下调整。

| 事项 | 初版决策 |
|---|---|
| Bot 身份 | 持久保存成员身份，与私聊会话、各群内的执行会话分开；内部执行会话不重复显示在成员列表。 |
| 默认模型 | 未单独选择模型的 Bot 在首次请求时使用基础模型，之后保留 Session 选择。P1 支持每个 Bot 固定选模；后续全局变更的自动跟随归 P4，需要安全的提示词准入接入。 |
| 工作文件 | 在 Katcats 工作根目录内为 Bot 和群分配默认目录，也允许指定项目目录；逻辑分组不改变路径或权限，切换目录保留原文件。 |
| 群内接话 | 新群仅包含明确选择的 Bot，负责人可选，也可在群内指定。聊天容器不运行协调模型，真实成员自行接话或跳过，明确点名直接交给对应成员。群内职责与私聊身份、其他群分别保存。成员回复采用独立聊天气泡，显示头像和姓名；明确接力上限、暂停、继续和停止。 |
| 记忆 | 区分 Bot、群和团队记忆，不自动向群内注入私聊原文或摘要，跨上下文共享必须明确。 |
| 权限 | 从首个可执行功能开始接入 DSH 工具与审批接口，Bot 不能自行扩大权限；文件位置分开不等于读取权限隔离。 |
| 生命周期 | 区分隐藏成员、停止当前任务和暂停定时任务；移除成员时保留共享文件和历史引用。 |

## 开发阶段

每个阶段交付一个可运行的增量。必需检查失败时先修复或明确分类，再进入下一阶段；不扩展为无关重构。

| 阶段 | 目标与交付 | 测试与验收 |
|---|---|---|
| P0：独立运行基线 | 建立项目内开发入口，分离 home、临时文件、日志和 Electron 存储，采用开发身份；独立准备构建依赖，构建源码基线并打开隔离预览。 | A01–A02；合成冲突环境测试；不使用旧配置或凭据，不注册系统命令、旧协议或执行更新；记录真实构建与启动结果。 |
| P1：成员与侧栏 | 增加持久化 Bot 与逻辑分组，固定主 Bot、默认两组、快速创建、私聊和右侧设置；复用现有视觉交互及已批准头像。 | A03–A06 的固定选模部分；领域与持久化测试、组件测试、浏览器创建/修改/重启检查，以及深浅色预览。 |
| P2：对话创建与身份 | 为主 Bot 注册创建和管理工具，与菜单共用成员服务；Bot 通过真实工具调用保存自己的长期角色。 | A07；脚本模型工具调用回放与失败案例；职责持久保存、不虚报成功、不把临时任务写成永久角色。 |
| P3：群聊协作 | 增加群成员和设置、独立成员执行会话、点名路由、自然接话选择、可见交接与可恢复接力暂停。 | A08 及 A09 执行控制；路由、多群与私聊并发测试；浏览器双成员协作；成员失败、退出或停止不会卡住整群。审批转呈随 P4/A11 完成。 |
| P4：团队能力对标 | 补齐私聊派活链、记忆与资料、文件交付、权限审批、定时任务、用量和中断恢复，通过公开接口保留 Katcat 现有工具。 | A06 自动跟随、A10–A13 及能力对标表全部条目；针对性的单元/集成/快照检查，合成密钥与重启 fixture，明确失败和取消状态。 |
| P5：产品验收 | 完成品牌、空态/加载/错误态、键盘操作、主题与动效，验收独立桌面预览和真实 DeepSeek 协作，形成使用与验证说明。 | 完整相关回归、最新构建产物后的构建检查、浏览器与未打包桌面检查，以及使用单独配置凭据执行真实模型 A07–A09。 |

## 验收场景

以下验收编号定义可观察结果。模型回放用于确定性验证调度流程，不能替代最后的真实模型检查。

| 编号 | 场景与通过条件 |
|---|---|
| A01 | 注入虚假的模型密钥、旧 home 和桌面标志；启动器不继承这些值，状态与缓存路径限制在本工程，不打开受保护位置；用合成 fixture 测试路径逃逸和链接路径。 |
| A02 | 不复制凭据打开独立预览，再重启；首次使用状态属于 Katcats，模型缺失时明确提示配置；Mock 模式明确标示，不能冒充真实模型验收。 |
| A03 | 初始侧栏有固定主 Bot，以及可见的空普通 Bot、群聊分组；创建、改名自定义 Bot 分组，并在分组间移动 Bot，不改变成员身份、文件或权限。 |
| A04 | 从全局菜单或分组加号输入名称、头像创建通用 Bot；创建不需要模型调用，分组归属、选中状态和重启持久化正确。 |
| A05 | 头像形态与颜色独立修改，使用已批准七款猫头和鲜亮色板，默认 classic、#FF2849；名称与头像在侧栏、对话和详情中一致更新。 |
| A06 | P1：尚未使用的 Bot 首次请求采用当前 Katcats 基础模型，创建不依赖模型凭据；测试成员固定覆盖、模型不可用、失败和输出期间修改，仅目标 Bot 改变，其他 Bot 与全局默认不变。P4：在提示词准入处验证全局自动跟随及图片一致性，通过后才开放该选项。 |
| A07 | 向主 Bot 请求创建角色，再对手动创建的 Bot 安排长期身份；工具结果、保存记录和界面一致，重启保留角色，无效请求或写入失败不报告成功。 |
| A08 | 选择两个 Bot 建群，不自动加入创建助手；测试可选负责人、无负责人协作，以及通过群内对话指定负责人和成员职责。重启保留群内设置，不改变私聊身份或其他群。发送点名任务并完成多步交接，成员身份和结果真实可见，内部执行会话不显示成额外成员。 |
| A09 | 同一 Bot 同时参与两群和私聊；测试普通群消息、点名、接力上限、暂停/继续/停止、等待审批、慢任务、单成员失败与重启，上下文和结果保持正确归属。 |
| A10 | 分别生成私聊文件和群共享交付物；切换工作目录不移动或删除旧文件；文件与命令工具不能绕过访问限制或使用其他产品配置。 |
| A11 | 保存、查看、修改和检索 Bot/群/团队记忆，显式共享上下文；测试审批允许/拒绝/取消/失效，确认 Bot 不能自行修改权限授权。 |
| A12 | 创建定时任务、暂停/恢复、查看用量并恢复中断派活；隐藏 Bot、停止当前任务、暂停定时任务具有分别验证的效果。 |
| A13 | 向群内下达明确任务：实际成员保存初稿，另一成员读取该文件并审校，原成员读取审校意见并保存最终交付物。从群内打开最终文件，核对内容，再通过后续追问取回产物。测试脚本不得替成员生成输出文件；发言、已排队工作与可用的最终交付分别验收。 |

## 测试与推进规则

- 每次修改执行所属模块的针对性测试、类型检查和相关回放快照；前端修改增加仓库 GUI 与浏览器检查，构建产物后再执行构建检查；记录实际命令和结果，包括基线失败。
- 持久化变更使用临时或合成数据及明确迁移 fixture，不以现有产品数据试验；验证部分写入与任务中断后的恢复。
- 使用明确标示的 Mock 模型进行可重复流程测试，最后用单独配置的真实 DeepSeek 模型验证协作；需要配置时使用新产品设置页，不要求在聊天中提供明文密钥。
- 阶段通过后更新证据和状态，简要汇报并继续；只有缺失信息、外部凭据或实质性破坏决策阻止安全推进时才询问，其余实现选择自主处理。
- 开发仅限本副本，不读写原应用及其用户数据、环境配置、`C:\Users\Administrator\.dsh`、`C:\Users\Administrator\AppData\Roaming\Katcat-desktop`，不复用其运行服务或已登录浏览器。
- 按需独立准备工程构建依赖，不打包、安装、卸载或发布桌面产品，不推送 Git，不擅自确定正式发布包名、appId、版本或发布地址；开发身份明确标为临时。
- 使用 DSH 公开插件 API、slots 和主题机制，不修改 DSH 循环。用户已批准[仅修改当前 Session 模型的扩展](proposals/session-model-scope.zh.md)、[提示消息模型准入](proposals/prompt-model-admission.zh.md)、[精确 Session 的群聊传输扩展](proposals/group-session-transport.zh.md)、[产品界面展示扩展](proposals/product-ui-presentation.zh.md)、[群成员点名发现](proposals/group-member-mentions.zh.md)及[复用当前 Session 的权限选择器](proposals/permission-picker-factory.zh.md)，不授权其他核心改动；保留已有用户修改、许可和字体声明。
