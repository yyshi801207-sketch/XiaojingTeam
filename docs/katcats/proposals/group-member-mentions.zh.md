# 群成员点名提案

[English](group-member-mentions.md) | 中文

## 状态与已确认的限制

本审阅参考对应[已批准的 API 补丁](group-member-mentions.patch)，在用户单独授权后仅应用于 Katcats 独立副本。用户要求群聊的 `@` 菜单只显示当前群的 Bot 成员。现有[引用来源](../../../packages/client/ui-reference/src/client/index.ts)查询文件和所有可发现的会话，而此前的[触发器注册表](../../../packages/client/ui-input-trigger/src/client/service.ts)为每个会话合并全部来源。产品层只增加成员来源，无法排除无关候选。产品注册和浏览器验收仍须单独验证，不能由此次 API 验证替代。

## 候选发现 API

补丁为 `InputTriggerSource` 增加可选的 `exclusive(session): boolean` 回调。同一会话与触发符下，只要有来源返回 `true`，候选发现、菜单点选和输入开头标记的空格匹配就只使用这些独占来源；否则沿用原来的有序来源列表。引用序列化、回车裁定、已保存声明恢复和引用预览仍使用完整注册表。多个独占来源明确允许共同贡献。既有来源不实现此回调，行为保持不变。回调只读取产品拥有的同步快照，不启动 I/O。

来源的词表失效、注册或移除时，控制器重建已打开的菜单：过时候选和标题消失，旧查询被取消，过期候选无法继续点选。即使移除最后一个显示中的来源导致菜单关闭，移除操作也会取消它尚在进行的查询。完整注册表仍用于引用序列化、旧草稿恢复和历史引用预览；发现策略不删除引用，也不授予其他会话访问权限。补丁不修改 Host API、传输类型、持久化格式或 Agent 循环。

## 产品整合

Katcats 拥有一个 `katcats-member` 来源，仅对已知群聊的记录会话独占 `@`，群目录重连期间仍保留这一声明；成员数据不可用时返回空列表并阻止序列化，不能退回全局会话列表。其他输入框沿用原有来源。候选由当前 `memberIds` 关联团队目录生成，显示已批准的猫头和成员姓名，不包含私聊会话、内部执行者标识或文件路径。切群和成员移出会使来源失效。同名成员用头像、群内职责辅助区分；仍然相同的名称按当前菜单的稳定列表顺序增加后缀。

点选插入携带稳定 `chatId` 和 `botId` 的产品引用，绝不生成 `dsh-session:` 引用。产品序列化器重新检查当前成员身份，再生成规范的 `@[name](katcats-member:<encoded-chat-id>/<encoded-bot-id>)` 文本；不打开或引用私聊、执行者的会话历史。产品自己的用户文本规则把已发送的文本显示为成员点名。Host 根据通过校验的 Bot 标识路由，要求文本中的群标识与目标群一致，拒绝已移出、外群和主创建 Bot，并在持久化接收前再次校验。同名成员也不会依赖姓名猜测。既有纯文本 `@姓名` 和历史会话引用保留原有校验与显示。

此次候选发现调整保留 `+` 的文件、图片附件入口，不改变 Bot 权限、审批、成员执行会话或普通文件预览。产品通过 `ctx.effect` 拥有注册和释放，不允许替换方法、访问私有注册表、仅用 CSS 过滤或拦截 DOM。

## 必须完成的验证

1. 注册表与控制器测试：默认和斜杠菜单保持不变；精确到会话、触发符的选择；多个独占来源；旧查询进行中使已打开菜单失效；过期鼠标和键盘点选；切群；移除来源；发现被抑制后仍可序列化既有引用、恢复旧草稿；释放后没有残留订阅。
2. 产品 Client 测试：只显示当前群成员及头像姓名；没有其他群、会话或文件路径；首次加载和重连拒绝回退；改名、同名成员；菜单打开时移出成员；成员移出后序列化被拒绝。
3. 产品 Host 测试：规范文本根据 `BotId` 路由；外群、非成员、创建 Bot、非法文本和已移出成员在接收前被拒绝；附件准入期间成员变更；没有调用私聊历史读取。保留既有同名纯文本点名拒绝规则和历史会话引用兼容。
4. 用全新隔离浏览器组合，通过原输入框和 `@` 菜单操作真实产品服务，仅外部模型使用 Mock；覆盖键盘选择、指定成员回应、切群、实时成员变更，以及 `+` 添加文件和图片。不使用已安装产品或真实用户数据。
5. 完成 API 与产品文档、针对性测试、类型检查和构建及构建检查，再更新独立预览。已应用 API 的服务测试通过 83 项，其中七项覆盖独占发现；此源码测试结果不能代表浏览器或已构建产品通过验收。
